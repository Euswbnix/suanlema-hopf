# 算了嘛，警官

> 警察：请出示驾照。　　　　司机：算了嘛，警官。\
> 警察：你有没有驾照？　　　司机：有。\
> 警察：有就请出示驾照。　　司机：算了嘛，警官。\
> 警察：不是，你有没有驾照？司机：有。\
> 警察：有就出示驾照。　　　司机：算了嘛，警官。\
> 警察：有没有驾照？　　　　司机：有。\
> 警察：你出示驾照。　　　　司机：算了嘛，警官。\
> 警察：师傅，请你尊重法律，我作为一个交警我现在郑重的请你出示驾照，你不要觉得我在跟你开玩笑。\
> 司机：（拿出驾照）

## 模型

把这段对话看成平面上的动力系统，用 Hopf 分岔的标准型（极坐标）：

$$\dot r = r(\mu - r^2), \qquad \dot\theta = \omega = \frac{2\pi}{5.05\ \mathrm{s}}$$

- **角度 θ**：对话进行到哪一句，逆时针依次是 盘问 → 有 → 请出示 → 算了嘛
- **半径 r**：离原点「出示驾照」有多远
- **μ**：司机嘴硬程度 − 警察强硬程度

|                  | μ > 0                                | μ < 0                        |
|------------------|--------------------------------------|------------------------------|
| 原点「出示驾照」 | **不稳定焦点**，往哪偏都被转着圈推开 | **稳定焦点**，转着圈收敛过去 |
| 极限环 r = √μ    | **稳定**，四句台词无限循环           | 不存在                       |

原点的雅可比矩阵是 $\begin{pmatrix}\mu & -\omega \\ \omega & \mu\end{pmatrix}$，特征值 $\lambda = \mu \pm i\omega$：实部决定稳不稳，虚部不为 0 所以是**焦点**（转着圈走），不是结点。

它也**不是鞍点**：鞍点的特征值是一正一负的实数（$\det J < 0$），有一条稳定流形能沿着走进去——对应「存在某种精准的问法能把司机引到掏驾照」。这里 $\det J = \mu^2 + \omega^2 > 0$，没有任何方向是吸引的，所以问法再巧也没用。另外平面上被极限环包住的不动点指标之和必须是 +1，而鞍点指标是 −1，本来也不可能单独待在圈里。

## 马尔可夫链

把四句台词看成四个状态，就是一条确定性的马尔可夫链：盘问 → 有 → 请出示 → 算了嘛 → 盘问，每条边 $p = 1$。它的周期是 4，平稳分布是各 1/4；「出示驾照」挂在「请出示」后面，但转移概率 $p = 0$，**不可达**。

视频里这四个节点的位置和相平面的四段一一对应，「出示驾照」放在正中间，正好就是原点那个不动点。转移概率跟着 μ 走：μ 穿过 0 之后，请出示 → 算了嘛从 1 变成 0，请出示 → 出示驾照从 0 变成 1，「出示驾照」成了**吸收态**——这就是 Hopf 分岔在马尔可夫链这层抽象上的样子。

## 视频里发生了什么

1. **循环（μ = 0.8）**：前 14 句按原视频顺序播，开场「请出示驾照 → 算了嘛警官」，接着三轮「有没有驾照 → 有 → 请出示 → 算了嘛」，每轮措辞都不一样。主角从离原点很近的地方出发，却被甩到极限环上；从别处出发的司机（灰色）也全都落到同一个圈上。极限环的 Floquet 乘子 $e^{-2\mu T} \approx 3\times10^{-4}$：偏离每转一圈只剩万分之三，所以重复问多少遍都没用。
2. **郑重声明**：警察不再重复，而是逐句说出那段话。从「我现在郑重的请你出示驾照」开始，一股强大的力量把 μ 在 2.5 秒内从 0.8 压到 −2，整个流场翻转，全部指向原点。
3. **Hopf 分岔**：μ 穿过 0 的那一刻极限环消失，原点从不稳定变成稳定焦点，轨迹螺旋收敛。
4. **拿出驾照**：话说完，系统已经收敛到原点，司机拿出驾照。

改变结局的不是再问一遍，而是 μ 变了号。

右下角的 **驾照出示概率 P(t)** 是阶梯状的：循环里盘问、有、请出示每句往上一个台阶（0.25 → 0.55 → 0.8），一句「算了嘛警官」直接清零，红虚线 1.0「出示驾照」从未到达；郑重声明时每句再上一个台阶，拿出驾照那一刻第一次到达 1.0。

## 自己渲染

```bash
pip install -r requirements.txt
python render.py                 # → media/suanlema_hopf.mp4，约 40 秒渲完
python render.py --gif           # 顺带把整段视频转成 media/preview.gif
python render.py --still 25      # 只导出第 25 秒一帧，调版面用
```

需要 `ffmpeg` 和一个中文字体（macOS 自带冬青黑体；Linux 可装 `fonts-noto-cjk`）。
